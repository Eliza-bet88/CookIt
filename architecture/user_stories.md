# CookIt User Stories

## Account Management

- As a new user, I want to register with my email and password so that I can create a personal CookIt account.
- As a registered user, I want to view my profile information so that I can check my account details.
- As a registered user, I want to update my name.
- As a registered user, I want to see my registration date so that I know when I joined CookIt.

## Profile and Preferences

- As a user, I want to select my cooking level so that CookIt can better understand my experience.
- As a user, I want to set a weekly cooking goal so that I can organise my cooking routine.
- As a user, I want to save personal notes so that I can keep useful cooking information in my profile.
- As a user, I want to choose favourite cuisines so that CookIt can recommend recipes that match my interests.
- As a user, I want to select more than one cuisine so that I can receive a wider range of recommendations.
- As a user, I want to set dietary preferences so that I can avoid unsuitable recipes.
- As a user, I want to add ingredients I dislike so that CookIt does not recommend unwanted food.
- As a user, I want to change my preferences at any time so that they reflect my current needs.

## Fridge Management

- As a user, I want to add a product to my fridge so that CookIt knows which ingredients I have.
- As a user, I want to enter a product quantity and unit so that my fridge information is clear.
- As a user, I want to add an expiry date so that I can use products before they expire.
- As a user, I want to view all products in my fridge so that I can see what is available.
- As a user, I want to edit a fridge item so that I can correct its quantity or expiry date.
- As a user, I want to remove a fridge item so that my fridge list stays up to date.

## Recipe Discovery

- As a user, I want to search for recipes by name so that I can find a specific meal.
- As a user, I want CookIt to find recipes using my fridge ingredients so that I can use products I already have.
- As a user, I want recipes with more matching ingredients to appear first so that I can choose the most suitable recipe.
- As a user, I want to see the number of matching ingredients so that I understand how well a recipe fits my fridge.
- As a user, I want to view recipe details and image so that I can decide whether I want to cook the meal.
- As a user, I want to see the recipe category and cuisine so that I can choose the type of food I want.
- As a user, I want to see the number of servings and cooking time so that I can plan my meal.
- As a user, I want to see all required ingredients and their amounts so that I can prepare the recipe correctly.
- As a user, I want to open the original recipe source so that I can access additional information when needed.

## Recipe Management

- As a user, I want to create my own recipe so that I can save a meal I know how to prepare.
- As a user, I want to add a title, description, category, and cuisine to my recipe so that it is organised clearly.
- As a user, I want to update my recipe so that I can correct or improve its information.

## Favourite Recipes

- As a user, I want to add a recipe to my favourites so that I can find it again quickly.
- As a user, I want to remove a recipe from my favourites so that the list remains useful.
- As a user, I want to view all favourite recipes in one place so that I can access them without searching again.
